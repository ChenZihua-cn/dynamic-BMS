# 实验报告：用 [BMS2020] 论文先验重跑钟摆实验（含力度消融）

> 路径提示（2026-10-18）：本日志写下的 `experiments/…` 钟摆产物现已整体移入
> `experiments/pendulum/`，映射见 `experiments/README.md`。

> 结论修正（2026-10-18 晚）：本报告的六档先验力度对照全部跑在**单温度**采样下，
> 而"命中链/占有率"这一列主要由采样器能否走出局部盆决定，不是先验力度的效应。
> 同一份 `wiki x1` 配置改用 20 温度并行回火后，主实验链级命中 8/64 → 64/64，
> 四个场景全部 100%——还原率就此饱和，不能再作该消融的因变量。
> 因此本报告的先验排序结论不成立；与采样无关的量（真公式 EP、MAP ops、
> 平均 EP、mixing）仍可用。先验对比要改在回火口径下重做。
> 另：本报告的"命中率"是样本级占有率，而命中在链级上是全有全无的，两者近似相等。

## 0. 结论速览

1. **可以，已经跑完。** 论文先验（`bms_wiki_nv13_np13`：18 个一阶项 + `*` 的二次项）
   经 `prior.get_prior_par()` 直接注入 `Tree(prior_par=...)`，走 core 原有的 `EP` 通道
   （`Nopi_` / `Nopi2_` 都已在 `get_energy` 与三个 `dE_*` 里实现），**零框架改动**。
   本轮把 `pendulum.py` 改造成先验可配置，用论文原值跑了 **64 条主链 + 32 条对照链**。

2. **先验校准确实兑现了它要解决的那个问题：MAP 从"怪物"变回教科书形式。**

   | | 手工平值先验（2026-10-16 那轮） | 论文 wiki 先验（本轮） |
   |---|---|---|
   | MAP 公式 | 23 个算子的怪物外衣 | `sqrt((L / g)) / _a_`（4 个算子） |
   | MAP 能量 − 真公式能量 | **+27.0 nat**（后验收敛到了错误表达式） | **−0.09 nat** |
   | 迹线平均复杂度 | 21.1 ops | 4.4 ops |

   那 0.09 nat 不是噪声：wiki 语料里 `/`（5.912）比 `*`（5.002 + 二次项 1.0 = 6.002）
   便宜 0.09 nat，所以后验更爱"除常数"写法而不是"乘常数"写法——这是语料统计
   直接体现在 MAP 上的可解释痕迹。审计 §4.2-4 的"先验未校准"到此有了实验答案。

3. **但命中率没有改善**：论文先验 8/64 = 12.5%，手工平值 3/14 = 21.4%，
   两者 95% 置信区间大幅重叠（[6.4%, 23.1%] vs [7.6%, 47.6%]），**统计上无法区分**。
   命中与否仍如审计 §3.4 所说是"全有或全无"的链级事件。瓶颈在**提议分布**，不在先验。

4. **代价是 mixing**：先验力度加大，链被冻住——相邻样本公式变化率从 0.33 掉到 0.03。
   弱信号场景（对照 B，仅地球 n=60）从 1/7 命中掉到 0/16（同样不能区分，但方向一致：
   强先验吞掉了需要先爬坡才能到达的结构）。

5. **顺带压掉了一个稳定性问题**：弱先验下生成的超深表达式会让 sympy 在假设系统里崩
   （`TypeError: Invalid NaN comparison`），flat-1.0 追加链时有 3 条链因此中途失败。
   论文先验下表达式小，这个问题不再出现。

## 1. 实验设置：先验怎么接进去的

### 1.1 注入路径（无框架改动）

```
prior/registry.py::get_prior_par('bms_wiki_nv13_np13')
        │  18 个 Nopi_<op> + 1 个 Nopi2_*（乘法二次项）
        ▼
Tree(prior_par=...)                       core/tree_base.py:66
        ▼
get_energy() 的 EP = Σ Nopi_o·n_o + Σ Nopi2_o·n_o²      core/energy.py:144
dE_et / dE_lr / dE_rr 中的 dEP 增量                      core/proposal.py
        ▼
paccept = exp(−dEB/BT − dEP/PT)·提议比                   core/mcmc.py
```

论文先验的数值（`archieve-9defb7aa/mcmc.py:1467`，上游
`Prior/final_prior_param_sq.named_equations.nv13.np13.2016-09-01 17:05:57.196882.dat`）：

```
-   3.35   pow2  3.30   *   5.00(+n²×1.0)   /   5.91   **    6.47
+   5.81   sqrt  4.76   exp 4.77   log 4.75   abs 6.33   pow3 5.99
sin 5.97   cos   5.45   tan 8.13   sinh 7.96  cosh 8.13  tanh 7.80   fac 10.0
```

对照：手工平值先验是 `Nopi_o = 1.0 ∀o`（无二次项）。真公式 `_a_*sqrt(L/g)` 的
`EP` 分别是 **16.68 nat**（论文）与 **3.0 nat**（手工）——相差 5.6 倍，这就是
本实验唯一的自变量。

### 1.2 脚本改造（`experiments/pendulum.py`）

| 新增 | 说明 |
|---|---|
| `--prior NAME [--scale F]` | 从登记表取先验；`--scale` 做整体调温（力度消融） |
| `--seed-offset N` | 种子与文件名整体平移，可在不覆盖已有迹线的前提下追加链 |
| `--chains-main/--chains-ctrl` | 链数可配（本轮主实验扩到 64 条以收紧置信区间） |
| run 目录 `pendulum_runs/<先验名>[_x尺度]/` | 不同先验的产物不再互相覆盖；旧结果归档在 `flat1.0/` |
| **MAP 指标** | 按后验能量 `E = BIC/2 + EP` 最小的样本，而非按 BIC 最小。**按 BIC 选最优会绕过先验**，只有按 E 选才看得到先验在做什么 |
| 复杂度 / mixing 指标 | 每个样本的 sympy `count_ops`、平均 `EP`、相邻样本公式变化率 |

其余（数据生成、宪法、判定标准、随机种子）与 2026-10-16 那轮完全一致，保证可比。

## 2. 主实验结果（论文原值，64 条主链）

| 指标 | 数值 |
|---|---|
| 真公式族占有率 | 3193/25600 = 12.5% |
| 命中链 | **8/64**（95% CI 6.4%–23.1%） |
| 有效常数 c\* | **6.2839**（2π = 6.2832，偏差 **0.011%**） |
| MAP 公式 | `sqrt((L / g)) / _a_`，4 ops，E = −634.5 |
| 参考真公式 E | −634.4 → **MAP 与真公式差 −0.09 nat** |
| 迹线平均复杂度 | 4.4 ops（中位 5），平均 EP 26.3 nat |
| mixing（相邻样本变化率） | 0.03 |

三个读法：

- **常数仍然测得极准**。c\* = 6.2839 与手工先验那轮一字不差——常数是数据项
  （BIC）决定的，先验几乎不参与，这是应该的。
- **MAP 是可读的**。`sqrt((L/g))/_a_` 就是 `T = (1/a)·√(L/g)`，与教科书形式只差
  "常数写成倒数"。后验最优解终于能被人类读懂。
- **占有率 12.5% 而不是更高**，说明后验质量仍在同一物理定律的多个"外衣"之间稀释
  （审计 §3.3 的常数折叠问题）：命中的 8 条链几乎全程停在真公式族（首次命中样本序
  都是 0），但各自停在不同的 canonical 家族里，简洁形式只占其中一部分。

对照组：对照 A（只给 L）0/16，对照 B（仅地球 L,g）0/16——见 §3 的讨论。

## 3. 先验力度消融：三条曲线

同一数据、同一种子、同一 MCMC 配置，只改先验力度（横轴 = 真公式在该先验下的 EP）：

| 先验（力度 EP） | 主实验命中链 | MAP ops | MAP−真公式 (nat) | 迹线 ops 均值 | mixing | 对照B命中 |
|---|---|---|---|---|---|---|
| flat 1.0（3.0） | 3/14 | 23 | +27.0 | 21.1 | 0.33 | 1/7 |
| wiki ×0.25（4.2） | 1/8 | 27 | +42.9 | 15.0 | 0.30 | 1/4 |
| wiki ×0.5（8.3） | 0/8 | 2（未命中） | — | 5.8 | 0.12 | 0/4 |
| wiki linear（15.7） | 2/8 | 5 | +4.75 | 3.9 | 0.05 | 0/4 |
| **wiki ×1（16.7）** | **8/64** | **4** | **−0.09** | 4.4 | 0.03 | 0/16 |
| wiki ×2（33.4） | 0/8 | 2（未命中） | — | 2.5 | 0.01 | 0/4 |

（完整表含对照 A/B：`experiments/pendulum_prior_ablation.md`；图：`experiments/pendulum_prior_ablation.png`）

**三条曲线各自的单调性完全不同，这是本轮最值得记住的一点：**

1. **MAP 简洁度：单调变好，且是硬收益。** 命中真公式的四个配置里，MAP 复杂度
   27 → 23 → 5 → 4 随力度单调下降，与真公式的能量差 +42.9 → +27.0 → +4.75 → −0.09
   单调趋零。这是先验校准的直接兑现，也是设计文档 P1 的验收标准。
2. **mixing：单调变差，且是硬代价。** 0.33 → 0.30 → 0.12 → 0.05 → 0.03 → 0.01。
   力度到 ×2 时链基本不动（变化率 1%），整条链被钉在 `(L + _a_/g)` 这类平庸式上。
   原因不难理解：每加一个算子要先付 5–8 nat，只有当 BIC 当场改善才可能被接受，
   而通往 `√(L/g)` 的路上必须先经过拟合极差的 `(L/g)`（审计 §3.2 的"独木桥"）。
3. **命中率：没有可分辨的趋势。** 1/8、0/8、2/8、8/64、0/8 —— 链数太小，
   且命中是全有或全无的链级事件。×0.5 与 ×2 的 0/8 与 ×1 的 8/64 在统计上不可区分。

### 关于对照 B（仅地球 n=60）从 1/7 掉到 0/16

方向上一致（强先验吞掉弱信号），但 0/16 的 95% CI 上界是 20.6%，1/7 的下界是 0.36%，
**不能据此断言"论文先验压掉了弱信号场景"**。要回答这个问题需要几十条链的专门实验。
能说的只是：论文先验没有**改善**弱信号场景的检出，而它确实大幅降低了 mixing。

## 4. 一句话回答"能不能按论文先验重做"

**能，而且应该——但不要期待它提高发现率。**

| 先验校准带来了什么 | 先验校准没有带来什么 |
|---|---|
| MAP 从怪物（23 ops）变回教科书形式（4 ops） | 命中率的可分辨改善（12.5% vs 21.4%，CI 重叠） |
| 后验最优与真定律的能量差从 +27 nat 降到 −0.09 nat | 更好的 mixing（反而从 0.33 崩到 0.03） |
| 表达式空间被裁到合理尺寸（迹线 21 → 4.4 ops） | 弱信号场景（对照 B）的检出 |
| 顺带消除了深表达式触发的 sympy 崩溃 | 常数精度的变化（本来就由数据决定，0.011%） |

审计 §4.3 列的六项改进里，**第 4 项（先验校准）已完成并验证有效**，
第 1 项（维度感知提议）与并行回火仍是命中率与 mixing 的真正瓶颈——本轮用 64 条链
再次确认了这一点：先验换了 6 档，命中率的噪声纹丝不动。

## 5. 局限与下一步

1. **命中率的统计效力不足**。除论文原值（64 链）外每个配置只有 8 条链。
   要给"先验是否影响命中率"一个确定的答案，需要每个配置 ≥ 50 条链
   （论文先验下 1.5 分钟/32 链，弱先验下慢得多且会崩，成本可用）。
2. **mixing 崩溃需要并行回火**。论文用 40 个温度 `T_k = 1.05^k`（[BMS2020] 式 12），
   core 目前只有单温度 `BT/PT`。强先验 + 单温度 = 链被冻死，这是当前最紧的瓶颈。
3. **canonical 常数折叠规范化仍未做**（审计 §4.3-2）。MAP 是 `sqrt(L/g)/_a_` 而不是
   `_a_*sqrt(L/g)`，占有率被稀释到 12.5%。做数值指纹归并后，命中链的占有率应接近 100%。
4. **弱先验下的 sympy 崩溃**：`Invalid NaN comparison`（sympy 假设系统在深表达式上
   递归爆掉）。建议给 `sympify` 与假设查询加保护，或把 `max_size` 从 50 降到 ~20
   ——反正论文先验下最优解只有 4 个算子。
5. **未触及的部分**：议会软先验（仅 Occam 可用、静态等权）、层次贝叶斯 `γ` 采样
   （"动态先验"的核心，仍是名而非实）、量纲类型化 PCFG（设计文档 P2）。
6. **实验设计本身**：只有单参数家族 `a`，没有干扰变量（m、θ₀），g 当作精确已知，
   舍入噪声是确定性的。审计 §4.3-6 提的改进都还没做。
