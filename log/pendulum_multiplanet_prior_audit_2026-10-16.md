## 0. 结论速览

1. **先验审计**：代码实现了 [BMS2020] 式（13）的结构先验*公式*（`EP = Σ Nopi_o·n_o (+ Nopi2_o·n_o²)`），并注入到 MCMC 接受概率中；但论文先验的*数据*——由 4080 条 Wikipedia 公式语料库经最大熵矩匹配（式 14）校准出的超参数 `a_o, b_o`——**没有进入本项目**：语料库与校准程序在仓库中不存在，实验使用的是手工平值 `Nopi=1.0`（代码默认 10.0）。项目自增的物理先验中，**量纲宪法已实现且生效**；议会软先验仅 Occam 可用且为静态等权；层次贝叶斯权重 `g_k` 的推断（本课题"动态"的核心）**尚未实现**（`gate/base.py` Phase 1，γ≡0 不采样）。论文的并行回火（40 个温度）也未实现。
2. **实验结果**：在米尺 0.01 m / 秒表 0.1 s 分辨率的多星球数据上，后验 MAP 恰好是真定律 `T = c·√(L/g)`（最优 BIC −1302.2 与真公式参考 BIC 完全一致），有效常数 c\* = 6.2839（2π = 6.2832，偏差 0.01%）。但 8 条链中仅 2 条在 8000 步内发现它；单星球只给 L 的对照组为 0%（原理性不可能）。
3. **水平定位**：结构发现（T ∝ √(L/g) 的幂律）本质上是量纲分析能免费给出的结论；真正从数据学到的物理内容是常数 2π（精度 0.01%）以及在合宪表达式空间内对竞争结构的排除。详见 §4。

## 1. 先验审计：对照论文检查先验的来源与注入位置

### 1.1 论文中先验的来源与注入位置

**[BMS2020] 的概率框架**（正文式 1–3）：

```
p(f_i | D) = (1/Z) ∫ dq_i p(D | f_i, q_i) p(q_i | f_i) p(f_i)      (式 1)
L(f_i) ≈ B(f_i)/2 − log p(f_i)                                     (式 3)
```

注入位置是后验/描述长度中的 `−log p(f_i)` 项，充当**结构复杂度正则化器**（论文明确：若设 p(f)=const 则退化为纯 BIC 模型选择，在巨大表达式空间中会结构性过拟合）。

**先验数据的来源**（[BMS2020] "Estimation of prior probabilities..." 一节与 Materials and Methods）：

```
−log p(f_i) = Σ_o [ a_o·n_o(f_i) + b_o·n_o²(f_i) ]                 (式 13)
```

- 语料库：Wikipedia "List of scientific equations named after people" 页面中解析出的 **4080 条公式**（启发式解析为 Sympy，人工抽查 3×200 条，错误率 <5%）；
- 校准：指数随机图/最大熵方法，迭代式（式 14）用 MCMC 生成百万级表达式做矩匹配，使生成表达式的各算子平均次数 `⟨n_o⟩` 及其平方 `⟨n_o²⟩` 与语料库一致，得到超参数 `a_o, b_o`（表格在补充材料 S3/S4）；
- 参数先验 `p(q_i | f_i)` 无显式形式，BIC 近似相当于假定其在峰附近平滑（弱信息）；
- 另有两个配套机制：canonical form 去重（同一表达式只保留一个代表树）与并行回火（40 个温度 `T_k = 1.05^k`，式 12）。

**[RSTA2026]**（综述）重申同一框架：式 5.1 给出同一最大熵先验 `p(m_i) = exp(−Σ_o (α_o n_o + β_o n_o²))`，强调先验是"复杂度"的显式、可审查的度量，且随数据量增大被边际似然冲刷（prior washes out）；同时指出可以（但本文未）使用"编码领域背景知识的更强先验"，引用了 Bartlett et al. 的符号回归先验工作（其 ref. [27]，含量纲类先验）。**两篇论文本身都没有把量纲分析作为硬约束使用。**

| 论文要素 | 代码位置 | 状态 |

### 1.3 明确结论

**当前实现没有使用论文意义上的先验数据。** 具体说：
- 结构先验的*通道*是通的（EP → 接受概率），但流经它的*数值*是手工设定的平值，不是从任何语料库校准来的；`a_o = 1.0 ∀o`、`b_o = 0` 意味着"每种算子每出现一次罚 1 nat"，是一个未校准的弱奥卡姆偏置。
- 唯一真正注入了领域知识的地方是**量纲宪法**（L/g 的量纲为 T²、`sqrt` 偶数性等），它来自我们手工声明的量纲表 `DIMS`，而非从数据或文献语料学习。
- 课题立项书中"先验权重 g_k 作为隐变量从数据推断"的动态机制尚未进入代码；当前所有先验权重都是静态的。

关键设计：5 个星球**合并为同一个数据集**，使拟合常数 `_a_` 跨星球共享。若按星球拆成多数据集，`get_sse` 会对每个数据集分别拟合参数（`core/energy.py:53` 的 `for ds in self.x` 循环），`_a_` 将逐星球取值——那会允许 `T = _a_·√L` 这类逐星球吸收入 √g 的错误结构，毁掉实验的可识别性。

### 2.2 先验参数与维度声明的入口

```
PRIOR_PAR = {'Nopi_<op>': 1.0 for op in OPS}（18 种算子）
     │ Tree(prior_par=...)（core/tree_base.py:66-69；若 {} 则默认 10.0）

                ──► 接受概率 paccept = exp(−dEB/BT − dEP/PT)·提议比（core/mcmc.py）

DIMS = {'L': (1,0,0,0,0,0,0), 'g': (1,0,−2,0,0,0,0)}（7 维 SI 指数）

     ──► collect_constraints() 遍历树，生成每个量纲维度的线性约束
     ──► solve_constraints() 做 Fraction 高斯消元 + sqrt 偶数性检查
```

注意：`DIMS` 中的 `'T'` 条目**没有被使用**——宪法只检查表达式内部一致性（加法两边同量纲、超越函数自变量无量纲、sqrt 输入指数为偶），并未把根节点量纲钉到目标量纲 T 上（`check_dimensional_consistency` 丢弃了 `root_exprs`）。因此输出量纲最终由 BIC 数据项把关。

## 3. 表达式树的生长机制与收敛过程

### 3.1 生长机制

树从单个随机叶子（L、g 或 _a_，概率均等）开始。生长/变异通过三类 move：

- **短程（et 替换，50%）**：任选一个以叶子为子树的节点，用 `et_space` 中的枚举单元替换（叶子↔单子树↔双子树），保持尺寸 ≤ max_size=50；
- **长程（节点换值，45%）**：保持子节点数不变，替换节点的算子/叶子值；
- **根替换（5%）**：在根上包一层算子（`sqrt(...)`、`* leaf` 等），或剪掉根。

每一步接受与否由 §2.3 的能量差决定。由于 `update_representative` 的去重，**同一 canonical 形式的表达式一旦留下代表，其它等价写法被永久拒绝**——链被强制持续探索新结构，不会在已见结构上堆积重复样本。

### 3.2 单摆定律的可达路径（宪法裁剪后的"独木桥"）

量纲宪法把通往真公式的自然台阶几乎全部拆掉：

| 中间形态 | 量纲判定 | 后果 |
|---|---|---|
| `_a_·√L`（单变量版真公式） | √ 内 L¹ 指数为奇 → **违宪** | 对照 A（只给 L）0/1600 命中，原理性不可能 |
| `√(_a_·L/g)`（参数进根号） | 参数系数 1 为奇 → **违宪** | 真公式只剩 `_a_·√(L/g)` 一种合宪写法 |
| `(L/g)`（无量纲参数） | 合宪（量纲 T²） | 拟合极差（E≈+1500），但它是必经之路 |
| `√(L/g)` | T² 开根号得 T，合宪 | 能量从 +1500 直落到 ≈−650 |
| `_a_·√(L/g)` | 合宪 | **真公式**，BIC=−1302.2，a=6.2839 |

实际收敛路径是：叶子 → `(L/g)` → 根包裹 `sqrt` → 根包裹 `* _a_`。瓶颈在中间一步：链必须先漂到拟合极差的 `(L/g)`（上坡 ~10³ nat，只能靠从同样差的邻居横跳过去），再恰好抽中 sqrt 根包裹（该状态下每步概率 ~0.05×0.5/|rr_space| ≈ 10⁻³），且不能在等待期间漂走。这解释了能量轨迹图（图 c）：8 条链中 6 条全程困在 E≈+180~580（RMS≈0.5 s 的平庸拟合，如 `L + c` 类），2 条在 burnin 期内完成跨越后稳定停留在 E≈−620（真公式能级），首次命中样本序均为 0。

### 3.3 "怪物外衣"：常数折叠不被 canonical 识别

命中真公式的链，其最优 BIC 样本并非简洁的 `_a_·sqrt((L/g))`，而是例如：

```
abs(sqrt(abs(((((fac((sqrt(tanh(tanh(fac(cosh(sin(tanh(_a_))))))) ** 3))
  ** (cos((tanh(_a_) / (g / g))) ** 3)) * abs(L))
  + (L * sinh((L / (exp(tan(_a_)) * -(L))))))
  / (-(g) + ((g / _a_) * cos((cos(_a_) + _a_)))))))
```

经数值验证（500 个随机 L,g 网格点，多个 _a_ 取值），该式与 `c(_a_)·√(L/g)` 的相对偏差在 **10⁻¹⁶ 机器精度**——它就是真公式，只是 `_a_` 被十几层常数折叠包裹（`fac(cosh(sin(tanh(_a_))))`、`cos(tanh(_a_)/(g/g))` 等都与数据无关）。因为 `canonical()` 只做 sympify 字符串规范化而不化简这类折叠，怪物与简洁形式属于**不同的 canonical 家族**，各自有代表树；链一旦在某家族留下代表就被冻结在那里（`update_representative` 返回 −1 拒绝同族其它写法），回不去简洁形式。后果：后验质量在同一物理定律的多个"外衣"间稀释，MAP 报告出来的是怪物而非教科书形式。

### 3.4 本轮数值结果（16 链，burnin=4000，thin=10，samples=400）

| 场景 | 真公式族占有率 | 命中链 | c\*（中位） | 最优 BIC | 参考 BIC（朴素真公式） |
|---|---|---|---|---|---|
| 主实验：5 星球，L,g | 774/3200 = **24.2%** | 2/8 | **6.2839** | −1302.2（属真公式族） | −1302.2（a=6.2839） |
| 对照 A：仅地球，L | 0/1600 = **0%** | 0/4 | — | −57.5 | — |
| 对照 B：仅地球，L,g | 400/1600 = **25.0%** | 1/4 | 6.2715 | −249.7（属真公式族） | −249.7（a=6.2715） |

两点说明：(i) 两轮运行使用相同随机种子，链轨迹相同，第二轮是修正分类器后的重分析而非独立重复实验，2/8 的命中率有二项起伏；(ii) 命中的链一旦到达几乎不再离开（占有率 ~97%/链），未命中的链全程未到达——**占有率是"全有或全无"的链级事件，不是平滑的后验质量**。

## 4. 结果评估：达到了什么水平，局限与改进方向

### 4.1 与物理学家的定性/半定量分析对比

物理学家**不需要任何数据**就能完成结构发现：单摆问题中只有 L、g、m、θ₀，由 Buckingham π 定理（或"周期的量纲是 T"这一句话）立即得到 `T = √（L/g)·f(θ₀)`，小角极限下 f≈常数——即 T ∝ √(L/g) 的幂律。常数 2π 才需要求解运动方程（或做实验测量）。

对照本轮结果，诚实的归因是：

- **结构部分（√(L/g)）**：机器确实从数据中独立选出了它——宪法只规定"量纲合法"，并没有把 `√(L/g)` 写进先验；合宪空间里还有 `_a_·L·g`、`_a_+L`、`_a_·L/√(gL)`（等价变形）等大量竞争者，是 BIC 数据项完成的选择。**但**搜索空间已被我们注入的量纲知识剧烈裁剪（`√L` 等被禁），所以结构发现是"量纲分析（人注入）+ 数据筛选（机器完成）"的联合产物，不能全部记到机器头上。
- **常数部分（2π）**：这是真正超出量纲分析的物理内容。机器测得 c\* = 6.2839（5 星球）、6.2715（仅地球），相对偏差 0.01% / 0.2%——在秒表 0.1 s 分辨率（最短周期处相对精度 ~10%）下，n=300 的统计平均把常数挤到了千分位。这一部分是合格的"实验物理学家"。
- **结论**：当前结果 ≈ 量纲分析的幂律水平 + 高精度常数测定。它验证了管线端到端可用，但还没有证明框架能在"量纲分析给不出答案"的问题上工作。

### 4.2 局限性

1. **发现成功率受混合瓶颈限制**：~25% 的链/8000 步，且全有或全无。宪法在砍掉违宪式的同时拆掉了自然台阶（§3.2），提议分布对量纲完全无感知，大量提议被硬拒绝浪费。
2. **canonical 去重不识别常数折叠**：MAP 以怪物形态出现（§3.3），可读性为零；同一物理定律的后验质量被稀释到多个 canonical 家族，占有率统计被系统性低估。
3. **根节点量纲未钉住目标**：宪法不约束输出量纲为 T（§2.2），`a·L` 这类量纲错误的式子合宪，选择全靠数据项；对更弱信号的问题这可能漏掉约束价值。
4. **先验未校准**：`Nopi=1.0` 平值使怪物与简洁形式的 EP 差只有 ~17 nat，不足以压制同 BIC 的怪物；若用论文语料库校准值（BMS 原文默认量级更大），简洁形式应在同 BIC 下压倒怪物。
5. **"动态"部分缺位**：议会仅 Occam 可用且等权静态，γ 不采样（§1.2）；对照论文还缺并行回火。当前系统本质上是"静态先验 BMS + 量纲硬约束"。
6. **实验本身的局限**：单参数家族（只放 `a`）、无干扰变量（未放 m、θ₀ 检验排除能力）、链间同种子复用、舍入噪声是确定性的（未加读数随机误差）、g 被当作精确已知。

### 4.3 改进方向（按优先级）

1. **维度感知提议分布**（PLAN 中的 5-D/联合提议方向）：在 et_space/rr_space 抽样时按当前节点的量纲缺口加权（例如需要 T² 量纲的子树时优先提议 `(L/g)` 类组合），把 10⁻³ 的独木桥变成主路；预期直接解决 25% 命中率问题。`test/test_statistics.py` 的拒绝率观测已预留了 <50%/50–80%/>80% 的升级决策规则。
2. **常数折叠规范化**：`canonical()` 中在 sympify 后对仅含参数的闭式子表达式做数值指纹（在若干随机参数点求值哈希）或限时 `sympy.simplify`，把怪物归并到简洁家族；同时修正 `update_representative` 的冻结副作用（`log/issue_fit_failure_lockin_2026-09-04.md` 记录的是同一族问题）。
3. **根量纲钉扎**：`check_dimensional_consistency` 已算出 `root_exprs`，加一步与目标量纲（如 T）的等式约束即可，成本极低。
4. **先验校准**：实现论文式 14 的矩匹配流程（或先用 BMS 官方仓库的拟合值替换平值 Nopi），让结构先验真正承载语料数据。
5. **实现 Phase 2 的 γ 采样**（课题核心贡献）与并行回火。
6. **实验升级**：加入干扰变量 m、θ₀（检验"排除法"），加随机读数误差，g 带测量误差，多组种子估计命中率置信区间，以及一个量纲分析不足以求解的基准问题（如含两个长度尺度的体系）。
